# bikecare

Трекер обслуживания для тех, у кого больше одного велосипеда. Тянет поездки из
Strava, считает износ каждой детали отдельно и собирает **один to-do список на
все велосипеды**, отсортированный по срочности: «Критично · просрочено на 813
км», «Через ~3 поездки», «Осталось 14 дней».

Ответ на челлендж повторить [mybikes.cc](https://mybikes.cc/).

```
python -m bikecare demo     # необязательно: выдуманный гараж из трёх велосипедов
python -m bikecare serve    # http://localhost:8765
```

Ни одной зависимости — только стандартная библиотека Python 3.10+
(`http.server`, `sqlite3`, `urllib`). Запускается и в Termux. База лежит в
`data/bikecare.sqlite` (или там, куда указывает `--db` / `BIKECARE_DB`).

## Что умеет

| Вкладка | Что там |
|---|---|
| To-do | всё, что съело ≥ 80% интервала, по всем велосипедам; клик — карточка с чек-листом «что подготовить» и кнопкой «Обслужено / Заменено» |
| Велосипеды | карточка сборки: детали, модель, интервалы, полоска износа; добавить / снять деталь, отправить велосипед на пенсию |
| Журнал | история работ со стоимостью; каждая запись обнуляет счётчик своей детали |
| Календарь | поездки, сделанные работы и прогноз — когда что подойдёт при нынешнем темпе |
| Поездки | из Strava или вручную; не тот велосипед — поменяйте, износ пересчитается |

## Как считается износ

У каждого типа детали (`catalog.py`) интервал в километрах, днях и/или
моточасах — **что наступит раньше**. Цепь — 3000 км, смазка — 300 км или 21
день, герметик — 90 дней, вилка — 50 часов и т.д. Всё переопределяется для
конкретной детали.

Километры — *эффективные*: каждая поездка взвешивается по тому, что она
сделала именно с этой деталью:

* гревел / MTB добавляют к износу цепи, колодок, роторов;
* набор высоты (м/км) — к колодкам и трансмиссии, с потолком 40 м/км;
* станок колодкам и покрышкам не идёт вообще, а цепи — полностью, обмотке
  руля (пот) — в полтора раза;
* коммьют +10%: светофоры, бордюры и любая погода.

Счётчик детали стартует с более поздней из двух дат: установка или последняя
запись в журнале. «Через ~N поездок» — по среднему эффективному пробегу за
последние 6 недель на этом велосипеде.

## Strava

1. Создайте приложение на <https://www.strava.com/settings/api>.
   *Authorization Callback Domain* — `localhost` (или хост, на котором
   открываете bikecare).
2. ```
   export STRAVA_CLIENT_ID=12345
   export STRAVA_CLIENT_SECRET=...
   python -m bikecare serve
   ```
3. В шапке появится «Подключить Strava». Доступ только на чтение
   (`read,profile:read_all,activity:read_all`); в Strava ничего не пишется.

Велосипеды из Strava появляются сами, с набором деталей под тип рамы. Поскольку
Strava не знает, когда вы меняли цепь, счётчики новых велосипедов стартуют с
момента подключения — поправьте дату у деталей через ⚙, если помните. Дальше
«Синхронизировать» в шапке или `python -m bikecare sync` из крона; повторная
синхронизация перечитывает последнюю неделю, чтобы поймать поменянный
задним числом велосипед.
